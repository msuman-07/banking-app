Case Study Question - 

A company is developing a simple Task Management Application. Two developers accidentally modify the same file. Initialize a Git repository and create a file config.txt with the content:“Task Management System Configuration”Commit it to the main branch. Create two branches: feature-notification and feature-deadline. In feature-notification, modify config.txt to add:“Notification feature enabled”Commit and push the branch. In feature-deadline, modify the same line in config.txt to add:“Deadline feature enabled”Commit and push the branch. Merge feature-notification into main. Then attempt to merge feature-deadline into main. Resolve the merge conflict by keeping both features in the file. Commit the resolved file, push changes, and delete both branches.
